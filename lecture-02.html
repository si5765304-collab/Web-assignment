Lecture 02 · HTML

HTML Document Structure

The skeleton every webpage is built on.

Summary

HTML marks up content with elements. Most elements have an opening and closing tag and can be nested inside each other.

A page starts with a doctype and an html root. The head holds metadata and the title; the body holds what visitors see.

page.html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Hello</title>
</head>
<body>
  <h1>Hi there</h1>
</body>
</html>

Key concepts

  • Doctype
  • head & body
  • Headings & lists
  • Links & images
Habit to buildAlways set the language, charset and a meaningful title.
