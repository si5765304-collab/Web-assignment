Semantic HTML

Choosing tags by meaning, not by looks.

Summary

Semantic elements such as header, nav, main, article and footer describe what a block is for.

This helps screen readers and search engines, and makes code easier to read. Pick the tag for its purpose, then style it with CSS.

layout.html
<header>
  <nav>...</nav>
</header>
<main>
  <article>...</article>
</main>
<footer>...</footer>

Key concepts

  • header / nav
  • main / article
  • section / aside
  • Accessibility
Rule of thumbIf a plain div has a clear job, there is probably a better tag for it.
