Flexbox in Practice

Sharing space, wrapping and real components.

Summary

Items can grow, shrink or keep a base size with flex-grow, flex-shrink and flex-basis, usually written as the flex shorthand.

Add flex-wrap: wrap so items drop to a new line when space runs out. This is great for navbars, toolbars and card rows.

cards.css
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
.card  { flex: 1 1 220px; }

Key concepts

  • flex shorthand
  • flex-wrap
  • Equal-height cards
  • Navbars
