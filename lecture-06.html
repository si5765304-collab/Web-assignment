Flexbox Basics

Laying items out in a row or a column.

Summary

Setting display: flex turns a container's children into flex items arranged along a main axis, chosen by flex-direction.

justify-content aligns along the main axis and align-items along the cross axis. gap adds space between items.

flex.css
.bar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Key concepts

  • Main & cross axis
  • flex-direction
  • justify-content
  • align-items
Pick a directionRow for side by side, column for stacked.
