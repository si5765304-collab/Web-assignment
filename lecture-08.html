Responsive Web Design

One page that works on every screen size.

Summary

Responsive design adapts layout to the space available. Start with the mobile layout, then enhance for wider screens.

The viewport meta tag makes phones use their real width, and media queries apply styles at chosen widths. Add a breakpoint when the content needs one, not for a specific device.

responsive.css
img { max-width: 100%; height: auto; }

@media (min-width: 768px) {
  .grid { grid-template-columns: 1fr 1fr; }
}

Key concepts

  • Viewport tag
  • Fluid images
  • Media queries
  • Mobile first
