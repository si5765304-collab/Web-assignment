Lecture 6: CSS Box Model & Layout

Spacing, sizing and positioning elements

Summary

Every element is a box made of content, padding, border and margin. Layout properties such as display and flexbox arrange these boxes on the page.

Topics Covered

  • Box Model
    • Content
    • Padding
    • Border
    • Margin
  • Layout
    • display property
    • Positioning
    • Flexbox

Example Code

<div style="padding:15px; border:3px solid orange; margin:10px;">
  A box with padding, border and margin.
</div>

Output

A box with padding, border and margin.
