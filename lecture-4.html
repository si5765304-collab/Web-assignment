Lecture 4: Introduction to CSS

Styling webpages with Cascading Style Sheets

Summary

CSS controls how HTML looks. This lecture shows the syntax of a CSS rule and the three ways of adding CSS to a page.

Topics Covered

  • CSS Syntax
    • Selector
    • Property
    • Value
  • Adding CSS
    • Inline
    • Internal
    • External
  • Text Styling
    • Colors
    • Fonts

Example Code

<p style="color:teal; font-size:20px;">
  This text is styled with CSS.
</p>

Output

This text is styled with CSS.
