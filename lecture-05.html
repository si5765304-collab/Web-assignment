The CSS Box Model

Why elements take up more space than you set.

Summary

Every element is a box made of content, padding, border and margin, from the inside outwards.

By default width only covers the content, so padding and border make the box bigger. box-sizing: border-box includes them in the width.

box.css
* { box-sizing: border-box; }
.box {
  width: 300px;
  padding: 20px;
  border: 2px solid;
  margin: 16px;
}

Key concepts

  • Content
  • Padding
  • Border
  • Margin
Inside outContent, then padding, then border, then margin.
