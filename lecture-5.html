Lecture 5: CSS Selectors

Choosing which elements to style

Summary

Selectors tell the browser which elements a rule applies to. We can select by element name, class or id, and combine selectors.

Topics Covered

  • Basic Selectors
    • Element
    • Class
    • ID
  • Combinators
    • Descendant
    • Child
  • Pseudo-classes
    • :hover
    • :first-child

Example Code

<style>
  .demo-note { color: crimson; font-weight: bold; }
</style>
<p class="demo-note">Styled by a class selector.</p>

Output

Styled by a class selector.
