CSS Fundamentals

Selectors, declarations and the cascade.

Summary

A CSS rule has a selector (who) and declarations (what). Each declaration is a property with a value, such as a colour or font size.

When rules clash, the cascade decides using importance, specificity and order. Reusable classes keep a stylesheet tidy.

style.css
.card {
  color: #222;
  padding: 1rem;
}
.card h2 { font-size: 1.4rem; }

Key concepts

  • Selectors
  • Properties & values
  • Specificity
  • External stylesheets
