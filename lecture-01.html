Introduction to the Web

How a browser turns a typed address into a visible page.

Summary

The web is a network of linked documents and apps reached through the internet. Every site is a bundle of files: HTML, CSS, images and scripts.

Typing a URL starts a chain: DNS finds the server, the browser sends an HTTP request, the server answers, and the browser draws the result. HTTPS encrypts that conversation.

request.http
GET /index.html HTTP/1.1
Host: example.com

200 OK
Content-Type: text/html

Key concepts

  • URL & DNS
  • HTTP request/response
  • Browser vs server
  • HTTPS
Remember the loopBrowser asks, server answers, browser renders. Everything else is detail on top of this.
