Lecture 7: Responsive Web Design

Pages that fit every screen size

Summary

Responsive design makes a website look good on mobiles, tablets and desktops using flexible layouts, fluid images and media queries.

Topics Covered

  • Key Ideas
    • Viewport meta tag
    • Fluid images
  • Media Queries
    • Breakpoints
    • Mobile-first approach

Example Code

@media (max-width: 600px) {
  body { background: lightyellow; }
}

Output

Resize your browser window below 600px to see the layout change on a real page.
